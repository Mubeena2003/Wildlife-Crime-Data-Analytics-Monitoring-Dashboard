# Wildlife Crime Data Analytics & Monitoring Dashboard

## Project Overview

This project is a data analytics portfolio project focused on analyzing wildlife crime records and developing a monitoring dashboard.

The project demonstrates data cleaning, validation, SQL analysis, trend identification, data visualization, and analytical reporting using Python, Pandas, SQL, MS Excel, and Power BI.

> **Disclaimer:** This project uses a synthetic dataset created for educational and portfolio purposes. It does not contain official, confidential, or operational data from the Tamil Nadu Forest and Wildlife Crime Control Bureau (TNFWCCB).

## Objectives

* Analyze wildlife crime case records.
* Identify crime patterns and trends.
* Analyze district-wise and species-wise incidents.
* Monitor high-risk and unresolved cases.
* Perform data quality and validation checks.
* Develop an interactive Power BI monitoring dashboard.
* Prepare analytical reports and KPI summaries.
